╔══════════════════════════════════════════════════════════════════════════════╗
║  🚀 3-STEP QUICK START                                                       ║
╚══════════════════════════════════════════════════════════════════════════════╝

    STEP 1: Collect Training Data
    ───────────────────────────────────────────────────────────────────────
    $ python data_collection_words.py
    
    • Show each word's hand gesture in front of camera
    • Press 'c' to capture ~1000 images per word
    • Press 's' to skip to next word
    • Press 'q' when done
    
    ⏱️  Duration: 10-15 minutes
    📁 Output: dataset_words/ folder with 5 subfolders


    STEP 2: Train the Model
    ───────────────────────────────────────────────────────────────────────
    $ python train_words_model.py
    
    • Loads images from dataset_words/
    • Trains MobileNetV2 using transfer learning
    • Splits data: 80% training, 20% testing
    • Saves model to model_words/
    
    ⏱️  Duration: 15-30 minutes (faster with GPU)
    📁 Output: model_words/{keras_model.h5, labels.txt}


    STEP 3: Test & Deploy
    ───────────────────────────────────────────────────────────────────────
    Option A - Test Words Recognition Only:
    $ python main_words.py
    └─ Real-time recognition of the 5 words
    
    Option B - Full Multilingual App (Recommended):
    $ python Multilingual_recognizer_with_numerals.py
    └─ GUI with buttons: ASL | ISL | Numerals | Words ⭐


╔══════════════════════════════════════════════════════════════════════════════╗
║  💡 TIPS FOR BEST RESULTS                                                    ║
╚══════════════════════════════════════════════════════════════════════════════╝

    Data Collection:
    ✓ Use consistent, good lighting
    ✓ Keep hand centered and clearly visible
    ✓ Vary angle and distance slightly
    ✓ Collect 1000+ images per word
    ✓ Involve multiple people for better generalization

    Training:
    ✓ Use GPU if available (much faster training)
    ✓ Monitor validation accuracy during training
    ✓ Collect more data if accuracy < 80%

    Recognition:
    ✓ Show gesture clearly in camera frame
    ✓ Hold steady for 1-2 seconds
    ✓ Maintain consistent lighting as training
    ✓ Stand 0.5-1.5 meters from camera


╔══════════════════════════════════════════════════════════════════════════════╗
║  🎓 TECHNICAL SPECIFICATIONS                                                ║
╚══════════════════════════════════════════════════════════════════════════════╝

    Model Architecture:
    ├─ Input:           224×224×3 RGB image
    ├─ Base Model:      MobileNetV2 (pre-trained on ImageNet)
    ├─ Global Pooling:  Reduces spatial dimensions
    ├─ Dense Layer:     128 neurons (ReLU activation)
    ├─ Dropout:         30% regularization
    └─ Output:          5 neurons (Softmax) → 5 words

    Training Configuration:
    ├─ Optimizer:       Adam (learning_rate=0.001)
    ├─ Loss Function:   Sparse Categorical Crossentropy
    ├─ Batch Size:      8
    ├─ Epochs:          30
    ├─ Train-Test:      80-20 split with stratification
    └─ Metrics:         Accuracy

    Expected Performance:
    ├─ Training Accuracy:    85-95%
    ├─ Testing Accuracy:     75-85%
    ├─ Real-time FPS:        20-30 fps
    └─ Recognition Latency:  30-50 ms
