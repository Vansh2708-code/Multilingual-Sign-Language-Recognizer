## 📁 New Python Scripts

### **1. `train_numerals_model.py`** - Training
```
Purpose: Train neural network to recognize numerals 0-9
Input: Images from dataset_numerals/0-9/
Output: Trained model in model_numerals/
Time: 15-30 minutes
Run: python train_numerals_model.py
```

### **2. `data_collection_files/data_collection_numerals.py`** - Collect Data
```
Purpose: Capture hand gesture images from webcam
Input: Live webcam feed
Output: Saved images in dataset_numerals/0-9/
Time: 30-40 minutes (manual work)
Run: python "Data_collection files/data_collection_numerals.py"
Key: Press 'c' to capture, 'q' to quit
```

### **3. `main_numerals.py`** - Test Numerals Only
```
Purpose: Real-time recognition of numerals 0-9
Input: Live webcam
Output: Recognized numeral + confidence
Time: Quick test
Run: python main_numerals.py
Key: Press 'q' to quit
```

### **4. `Multilingual_recognizer_with_numerals.py`** - Full App
```
Purpose: Switch between ASL, ISL, and Numerals
Input: Live webcam + button clicks
Output: Recognized sign/numeral
Time: Quick test
Run: python Multilingual_recognizer_with_numerals.py
Feature: GUI buttons to switch modes
```
